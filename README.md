# iwamad-practice

Profile card for the IWaMAD course, built with React + TypeScript + Vite.
Week 04 adds pages (React Router), shared likes state (Context) and the first test (Vitest).

## Scripts

```bash
npm install
npm run dev      # local dev server
npm test         # Vitest + React Testing Library
npm run lint     # ESLint
npm run build    # type check + production build into docs/ (+ docs/404.html)
```

## Branches

- `week-01` … `week-04` — work for each week.
- GitHub Pages is published from `week-04`, folder `/docs`.

Live site: https://temirlan-amanzhol.github.io/iwamad-practice/
